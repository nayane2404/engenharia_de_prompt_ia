# Meu chat bot
# 🤖 Chatbot em Python (Terminal)

Chatbot desenvolvido em Python que interage com o usuário via terminal, respondendo perguntas de forma automatizada.
Projeto focado em lógica, automação e fundamentos de IA/conversação.

---

## 🚀 Demonstração

Exemplo de uso no terminal:

```bash
$ python chatbot.py

Você: Qual seu nome?
Bot: Eu sou um chatbot criado em Python!

Você: O que você faz?
Bot: Eu respondo perguntas simples no terminal.
```

---

## ⚙️ Funcionalidades

* Interação via terminal
* Respostas automáticas baseadas em regras
* Estrutura simples e fácil de expandir
* Base para integração com IA no futuro

---

## 🛠️ Tecnologias utilizadas

* Python 3
* Lógica de programação
* (Opcional) Bibliotecas como `random`, `re`, etc.

---

## ▶️ Como executar o projeto

1. Clone o repositório:

```bash
git clone https://github.com/[seu-usuario]/[nome-do-repo].git
```

2. Acesse a pasta:

```bash
cd [nome-do-repo]
```

3. Execute o chatbot:

```bash
python chatbot.py
```
